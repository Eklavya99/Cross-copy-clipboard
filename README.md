# CrossClip

A second, shared clipboard between your Windows and Ubuntu machines.

- `Ctrl+Alt+C` / `Ctrl+Alt+X` — copy or cut the selection into the Cross Clipboard; it is sent to the other machine immediately.
- `Ctrl+Alt+V` — paste the Cross Clipboard item on either machine.
- Your normal `Ctrl+C` / `Ctrl+V` clipboard is left untouched.

Text, code and images are supported. Traffic is encrypted and limited to paired
devices on your local network. Each side is a tiny background process with no
runtime dependencies.
